# Ustawienia UPR Terminal

Powiadomienia: centrum powiadomień, dymki systemowe i natywny dźwięk.
Aplikacja: autostart zapisuje się automatycznie; statystyki zapisuje przycisk zapisu ustawień. Brak zakładki publicznego WWW.

Rozwijane sekcje są domyślnie zwinięte. Przełączanie zakładek ustawień nie
kasuje ich stanu, zapis i wyjście z ustawień zwijają sekcje.
Format starej konfiguracji i pliki sekretów pozostają zachowane.
